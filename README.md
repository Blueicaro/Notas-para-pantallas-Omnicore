# 📱 Notas para Pantallas Omnicore

Recopilación de notas técnicas sobre cómo programar interfaces (HMI) en robots ABB OmniCore utilizando AppStudio.

## 🎯 Objetivo / ¿Qué es esto?

En esta guíaencontrás fragmentos de código en javascript, que es el lenguaje en el se programa las pantalla de los robot ABB Omnicore. 

 [Accede al documento](https://github.com/Blueicaro/Notas-para-pantallas-Omnicore/blob/main/AppStudio%20Notas.md).

## ⚙️ Requisitos previos

Conocimientos de robots ABB, programación y JavaScript.
